# 压入式装盒项目简版说明（甲方沟通版）

## 1. 项目目标

本项目的目标是让机械臂把燕窝玻璃瓶自动放入包装盒指定槽位，并在最后一段压入过程中具备接触检测、过压保护和安全回退能力。

这不是从零开始的新项目，而是在现有抓取和基础放置 demo 的基础上，增加腕部定位相机和力控能力，完成从“能抓能放”到“能稳定装盒”的升级。

## 2. 最终预估装盒效率

按当前方案评估，在“单一瓶型 + 单一盒型 + 单工位”的前提下：

- 首版目标节拍：`6-8 秒 / 瓶`
- 首版目标成功率：`>= 95%`
- 首版目标破损率：`0`

说明：

- 这个节拍是首版工程目标，优先保证稳定闭环，不以极限速度为第一目标
- 后续如果增加工装优化、相机布局优化或节拍专项优化，效率还有继续提升空间

## 3. 动作大概拆解

对甲方可以简单理解为 6 个动作：

1. 识别包装盒和目标空槽
2. 抓取待装盒的玻璃瓶
3. 移动到目标槽位上方
4. 用腕部定位相机做最后一次对位修正
5. 低速下探，检测接触并按目标力压入
6. 松爪、回退、记录结果

## 4. 新增硬件部分

当前方案下，新增硬件主要有两项：

- 六维力/力矩传感器
  - 用于接触检测、过压保护、偏斜识别和压入力控制
- 腕部定位相机
  - 用于识别盒位、空槽位置，以及压入前的最终对位

条件性新增硬件：

- 取料区固定视觉
  - 如果现有取料识别链路稳定，就可以不新增
  - 如果现有取料识别不稳定，再补这一部分

可选优化项：

- 夹爪软质防滑摩擦片
- 简单导向治具
- 顶视工位相机（后续做节拍优化时再考虑）

## 5. 目前进展

当前已经完成的部分：

- 机械臂视觉识别、抓取、抬升、搬运和基础放置 demo 已经跑通
- 白色不透明瓶的抓取和放置已经重复验证成功
- 现有系统已经具备基础控制链路、相机采集链路和任务编排基础

当前还没有完成的部分：

- 六维力/力矩传感器的正式接入
- 腕部定位相机在装盒工位上的识别与对位
- 压入式装盒的接触检测、恒力压入和到位判断

一句话概括当前状态：

- 抓放底座已经有了，下一阶段主要是在此基础上补齐“装盒最后一段”的接触式操作能力

## 6. 未来工作

下一阶段工作可以拆成 4 部分：

1. 接入力/力矩传感器和腕部定位相机，完成安装、通信和标定
2. 完成包装盒 / 空槽识别，以及压入前的近距对位修正
3. 完成接触检测、过压保护、恒力压入和回退逻辑
4. 做整链路联调、稳定性优化和现场验收

## 7. 研发周期

在“单一瓶型 + 单一盒型 + 硬件及时到位”的前提下，建议按下面的研发周期对外沟通：

- 可演示首版：`4-6 周`
- 稳定优化版：`6-8 周`

一个相对容易理解的拆分方式是：

- 第 1 周：硬件安装、通信打通、基础标定
- 第 2-3 周：腕部定位相机识别与装盒对位
- 第 3-4 周：接触检测、压入控制、回退保护
- 第 5-6 周：整链路联调、参数优化、演示验证
- 第 6-8 周：稳定性优化、异常处理和现场验收

## 8. 对甲方的核心结论

这个项目的价值，不只是“让机械臂把瓶子放进盒子里”，而是把现有系统升级为：

- 能识别目标槽位
- 能在接触过程中判断异常
- 能按目标力完成压入
- 能在异常时保护产品并安全退出

从项目属性上看，这属于在现有 demo 基础上的增量开发，不是从零开始重做整套系统，因此周期和风险都相对可控。
