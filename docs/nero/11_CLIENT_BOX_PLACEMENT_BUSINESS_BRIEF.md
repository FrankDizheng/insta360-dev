# 压入式装盒项目商务说明（甲方沟通版）

本文件用于甲方前期沟通，重点说明项目价值、首版交付范围、技术边界和研发周期，不替代最终技术协议或正式报价文件。

## 1. 项目概述

本项目面向燕窝玻璃瓶压入式装盒场景，目标是在现有机械臂抓放 demo 基础上，进一步实现：

- 自动识别包装盒和目标空槽
- 自动抓取玻璃瓶并移动到目标槽位上方
- 在最后一段压入过程中完成接触检测、过压保护和安全回退

项目的核心价值，是把现有系统从“能抓能放”升级为“能稳定装盒、能处理接触过程异常”的工程化方案。

## 2. 商务交付目标

首版交付希望让甲方看到的是一个可演示、可验证、可继续扩展的自动装盒能力，而不是停留在单点动作演示。

首版完成后，系统应具备以下结果：

- 能完成指定瓶型到指定盒型的自动装盒
- 能在压入前完成最后一次视觉对位修正
- 能在压入过程中监测接触和异常
- 能在异常时停止动作并安全退出，降低产品损伤风险

## 3. 首版技术边界




### 3.1 首版适用范围

- 首版只针对单一瓶型、单一盒型
- 首版默认按单工位场景评估和交付
- 首版重点验证“稳定闭环可运行”，而不是一次覆盖多规格、多工位、多产线

### 3.2 首版效率目标边界

- 首版目标是跑通稳定闭环，不追求量产极限节拍
- 首版目标节拍为 `6-10 秒 / 瓶`
- 如果甲方后续要求更高节拍，可在首版验证完成后进入专项优化阶段

### 3.3 首版实施边界

- 本阶段沿用现有平台架构，只做增量扩展
- 重点新增的是腕部定位相机、六维力/力矩传感器，以及压入阶段的软件能力
- 本阶段不是从零开始重做整套机器人系统，也不是重做整套平台架构

### 3.4 当前阶段不默认承诺的内容

以下内容建议在首版商务沟通中明确标注为“后续可扩展项”，不默认包含在当前阶段：

- 多瓶型 / 多盒型自动切换
- 多工位并行装盒
- 量产级极限节拍优化
- 与整线 MES / WMS / 上游下游设备的完整系统集成

如果甲方有上述需求，建议在首版验证完成后，作为第二阶段单独规划。

## 4. 最终预估装盒效率

在“单一瓶型 + 单一盒型 + 单工位 + 硬件及时到位”的前提下，当前建议的首版目标如下：

- 目标节拍：`6-10 秒 / 瓶`
- 目标成功率：`>= 95%`
- 目标破损率：`0`

补充说明：

- 以上目标更偏工程首版目标，优先保证稳定性和可交付性
- 后续如增加工装优化、导向治具、视觉布局优化和节拍专项调优，效率还有进一步提升空间

## 5. 动作大概拆解

从甲方视角，可以把整套动作理解为 6 个步骤：

1. 识别包装盒和目标空槽
2. 抓取待装盒的玻璃瓶
3. 移动到目标槽位上方
4. 用腕部定位相机完成最后一次对位修正
5. 低速下探，在接触检测基础上按目标力压入
6. 松爪、回退、记录结果

## 6. 新增硬件部分

当前方案下，首版新增硬件主要为项：

- 六维力/力矩传感器
  - 用于接触检测、过压保护、偏斜识别和压入力控制

条件性新增硬件：

- 取料区固定视觉
  - 如果现有取料识别链路稳定，可以不新增
  - 如果现有取料识别不稳定，再补充配置
- 放置区固定视觉
  - 如果现有放置识别链路稳定，可以不新增
  - 如果现有放置识别不稳定，再补充配置
可选优化项：

- 夹爪软质防滑摩擦片
- 简单导向治具
- 顶视工位相机

## 7. 目前进展

当前已经具备的基础：

- 机械臂视觉识别、抓取、抬升、搬运和基础放置 demo 已经跑通
- 白色不透明瓶的抓取和放置已经重复验证成功
- 现有系统已具备基础控制链路、相机采集链路和任务编排基础

当前还需要补齐的核心能力：

- 六维力/力矩传感器的正式接入
- 压入式装盒的接触检测、恒力压入和到位判断

一句话概括当前状态：

- 现阶段已经具备抓放基础，下一步主要是补齐“装盒最后一段”的接触式操作能力

## 8. 未来工作

下一阶段工作建议拆成 4 部分：

1. 接入力/力矩传感器和腕部定位相机，完成安装、通信和标定
2. 完成包装盒 / 空槽识别，以及压入前的近距对位修正
3. 完成接触检测、过压保护、恒力压入和回退逻辑
4. 完成整链路联调、稳定性优化和演示验收

## 9. 研发周期

在“单一瓶型 + 单一盒型 + 硬件及时到位”的前提下，研发周期如下：

- 可演示首版：`4-6 周`
- 稳定优化版：`6-8 周`

详细如下：

- 第 1 周：硬件安装、通信打通、基础标定
- 第 2-3 周：顶部定位相机识别与装盒对位
- 第 3-4 周：接触检测、压入控制、回退保护
- 第 5-6 周：整链路联调、参数优化、演示验证
- 第 6-8 周：稳定性优化、异常处理和现场验收

## 10. 项目定义

本项目定义为：

- 一个基于现有 demo 的增量升级项目
- 一个风险相对可控、周期相对明确的首版工程项目
- 一个先完成单型号闭环，再逐步扩展到更多规格和更高节拍的分阶段项目
