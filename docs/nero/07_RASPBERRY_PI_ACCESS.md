## 4. 使用说明

- 当笔记本和树莓派同时接入同一个 Tailscale 网络时，不需要接入现场局域网，也可以直接 SSH
- 如果人在现场、并且笔记本已经接入同一个局域网，仍可继续使用 `ssh pi@10.13.167.212`
- 如果树莓派更换网络、DHCP 重新分配地址，局域网 IP 可能变化
- 如果 Tailscale 正常在线，优先使用 Tailscale 地址，避免受现场网络和 VPN 影响
- 文档只记录连接地址，不记录密码
